# 工作台使用

[文档导航](README.md) · [部署与启动](getting-started.md)

## 连接

后端启动后打开 [工作台](http://localhost:8000/test.html)，输入对应身份的 API key。页面会自动签名请求并验证响应，菜单按身份显示。密钥只保存在当前页面内存，刷新后需重新连接。

管理员可切换代操作出票方；切换会清除待出票选择。运营方独立密钥仅显示其承运客票与附加信息功能，不具备出票方权限。

## 查询与出票

1. 从车站区间查询，或从班次列表选择上、下车站序。
2. 用日期、运营方、车厂、车次号和发车时间窗口缩小结果范围。
3. 确认具体班次 ID、UTC 到发时刻、区间里程、票价和余票。
4. 填写旅客姓名，或选择全局证件库中的证件用于出票。
5. 出票后保存票号及 PNR；同一请求键重试返回同一张票。

班次显示可切换组合标识与数据库 ID，出票始终使用数据库 ID。同号车次与环线重复停站需确认具体时刻和站序。

查询报价后修改公里单价，出票时会提示重新查询。缺少可靠里程时禁止新出票，需先导入或回填数据。

## 车厂与班次

车厂选择器显示当前地图完整目录，包括零班次车厂。选择后可查看股道、车辆上限和无法计划的具体原因。修改日期、运营方或车厂筛选会回到第一页。

管理员可设置车厂归属运营方，或调整未出票班次的运营方；已有客票（包括已退票）的班次不能更换承运方。

## 管理菜单与列表

管理员左侧使用 TDesign 二级菜单，每个子项都是独立页面：

| 一级菜单 | 独立页面                                               |
| -------- | ------------------------------------------------------ |
| 机构管理 | 运营方、出票方、授权与密钥、出票白名单、车厂与班次归属 |
| 业务配置 | 车站字典、票价规则、车底管理                           |
| 数据维护 | 运营日清理                                             |

运营方、出票方和车站字典采用列表优先展示，支持搜索与分页；点击新增或编辑才展开表单，保存或取消后收起。车厂归属页提供完整车厂列表，可搜索车厂、维度或运营方，从列表定位归属设置。切换页面保留已加载列表与未提交表单，退出连接后关闭编辑面板。顶部标题及面包屑与当前子菜单对应。旧 `#/management` 地址重定向到运营方列表。

机构代码及出票方三位票号前缀创建后不可变。「授权与密钥」维护出票方的运营方授权，「出票白名单」维护运营方的销售名单；密钥轮换只在本次响应显示明文，旧密钥立即失效。

「业务配置 → 票价规则」以限速档列表维护每公里单价，单位为分/公里（CNY）。单价随速度严格递增，保存时检查版本。初始化费率仅为演示值，实际运营前应调整，详见 [里程计费](mileage-fares.md)。「业务配置 → 车底管理」维护席位、票额与倍率，详见 [车底库存](rolling-stock.md)。

## 证件与运营方附加信息

“旅客证件库”支持登记、修改、查询和修改日志。创建及修改需填写原因；旧版本编辑会提示重新加载。历史客票显示出票时的证件快照。

“运营方客票 / TLV”支持浏览自身承运客票、追加附加信息、撤销、查看审计和导出二进制流。管理员使用该功能需明确选择运营方范围。

## 按运营日清理

在「数据维护 → 运营日清理」先选择日期和范围预览，再输入同一日期确认执行。日期是班次 UTC 运营日，包含所有维度、历史导入版本及跨午夜停站。

| 范围        | 清理内容                                            |
| ----------- | --------------------------------------------------- |
| `all`       | 当日运行图及关联客票                                |
| `tickets`   | 客票、乘车联、幂等请求、客票及 TLV 审计，保留运行图 |
| `timetable` | 停站、班次及导入批次；有关联客票时拒绝              |

车站、地图目录、机构、密钥和全局证件库保留。执行删除会重新校验，操作不可撤销。

命令行默认也仅预览：

```bash
php think ticketing:clear-date --date=2026-10-26 --scope=timetable
# 确认预览后才加 --execute 永久执行
```

参数和管理员接口见 [接口文档](external-api.md)。

## 车站字典

在「业务配置 → 车站字典」搜索导入车站，点击编辑后填写唯一三字母电报码、单一归属运营企业、中英文名及两级行政区，再设置可见性并保存。行政区为自由输入。未配置站默认隐藏；重新导入保留字典配置。参见 [配置与 API](station-dictionary.md)。
